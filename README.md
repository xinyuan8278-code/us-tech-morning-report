# 美股科技板块前一交易日行情日报 —— 网页版

## 这是什么
一个可部署到 Vercel 的静态网页模板。页面结构按华泰研究风格搭建，用于生成《美股科技板块前一交易日行情日报》（盘前版）。

## 每日如何更新
**自动更新**：已配置「每天 09:30」的定时任务，自动抓取【前一个美股实际交易日】的行情与新闻，更新 `data.js` 中除涨跌幅以外的全部内容。更新后 `git push` 自动触发 Netlify 重新部署即生效。

手动更新（备用）：
1. 打开 `data.js`，替换里面的数据（报告日期、交易日、市场概览、指数、超涨超跌提示、重点公司行情表、新闻、交易逻辑、关注事项）。
2. 保存后，把整个文件夹重新部署到 Netlify/Vercel 即可（或本地双击 `index.html` 预览）。

## 文件说明
- `index.html` —— 页面结构与样式（**一般无需改动**）
- `data.js` —— **每日数据**（涨跌幅除外，其余由定时任务自动填充）
- `live.js` —— **行情自动接入**：从「腾讯自选股」拉取指数与重点公司的实时涨跌幅
- `report-prompt.md` —— **日报生成规范**：定时任务抓取内容所遵循的完整规则（时间、信息源、报告结构、质量要求）
- `assets/logo.png` —— 华泰期货 logo（顶部小图）
- `netlify.toml` —— Netlify 部署配置（推荐）
- `vercel.json` —— Vercel 部署配置（备选）
- `package.json` —— 占位配置，便于托管平台识别

## 行情数据来源（腾讯自选股）
- 指数卡片与「重点公司行情表」的**涨跌幅**会自动从腾讯自选股实时行情接口拉取并覆盖显示，无需在 `data.js` 里手工维护涨跌幅。
- `data.js` 中的 `change` 字段仅作**兜底**：当行情拉取失败（如离线/接口不可用）时，页面仍显示手工填写的数值。
- 指数代码映射：Nasdaq Composite→usIXIC、Nasdaq-100→usNDX、标普500→usINX、费城半导体指数→usSOXX（腾讯无 SOX 独立行情，用 SOXX ETF 代理）。
- 重点公司：按 `us` + 股票代码（如 NVDA→usNVDA）自动匹配，代码需为美股标准代码。
- 若某代码在腾讯无行情，该条仍显示 `data.js` 中的兜底值。

## 配色
纯白背景 + 浅蓝 + 黑色；涨用红色、跌用绿色（A 股习惯）。

## 部署到 Netlify（推荐）
**方式一：连接 GitHub，push 即自动部署**
1. 把本文件夹推送到 GitHub 仓库（HTTPS 或 SSH 均可）。
2. 登录 https://app.netlify.com → Add new site → **Import an existing project** → 选择该 GitHub 仓库。
3. Build command 留空、Publish directory 填 `.`，点 Deploy 即可。
4. 之后每次 `git push`（含每天 09:30 定时任务推送 data.js）都会自动触发重新部署。

**方式二：拖拽部署（零配置）**
1. 登录 Netlify → Sites → Add new site → **Deploy manually**。
2. 把整个文件夹拖进去，秒级上线（纯静态、无需构建）。

## 部署到 Vercel（备选）
```bash
cd 项目目录
vercel        # 一路回车即可，零配置
```
或拖拽整个文件夹到 https://vercel.com/new 直接托管。

## 数据填写规范
- 涨跌幅用百分比字符串：`+1.25%` / `-0.80%`；正数为涨（红）、负数为跌（绿）。
- 新闻 `news` 建议 5—10 条；交易逻辑 `logics` 建议 3 条。
- 无法填写的字段留空字符串 `""`，页面自动显示占位符，不要编造数据。
- 数组项可增删。
